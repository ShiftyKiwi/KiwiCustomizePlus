# Customize+ 4.3.1

## Live Template Editing

- Fixed Live Editing ignoring Advanced Body Scaling profile overrides and falling back to global ABS settings.
- Live Editing now preserves the active winning profile's ABS override context when editing one of that profile's enabled templates.
- Profile Context Preview now uses the same profile-context behavior.
- Nullable and inherited ABS overrides continue to resolve normally.

## Scope

- This is a maintenance fix for a pre-existing Live Editing integration issue.
- No new solver, native deformation, template persistence, profile persistence, IPC/API, or synchronization behavior was added.
