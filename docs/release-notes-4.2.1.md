# Customize+ 4.2.1

## Actor/Profile Application Fixes

- Fixed assigned Customize+ profiles failing to reapply to Event NPCs when entering or leaving GPose.
- Fixed assigned player profiles failing to apply in supported quest cutscenes when the game uses a separate cutscene character representation.
- Fixed profile application on the Character Select screen after the actor-selection hardening.
- Improved actor representation selection so Customize+ uses the authoritative valid representation rather than assuming the first grouped object is bindable.

Actor selection remains validated and fails closed when no unique bindable representation is available.
